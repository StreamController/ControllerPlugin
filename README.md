# Controller Plugin

A plugin for StreamController that adds controller and joystick functionality.

## Features

- **Joystick**: Control a virtual joystick with your Stream Deck
- **Joystick Buttons**: Create virtual gamepad buttons with your Stream Deck

## Requirements

This plugin requires the `evdev` Python package to work properly.

## Installation

This plugin is automatically available in the StreamController plugin store. You can install it directly from there.
